# Windows Installer Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Deliver a reversible Windows installer for the existing T3 Code Nightly.

**Architecture:** Share patching, dependency installation and JavaScript builds with the existing Python CLI. Isolate Windows discovery, archive packaging, backup and journaled replacement in windows.py, called through PowerShell launchers.

**Tech Stack:** Python standard library, PowerShell, Git, Node 24 and pnpm.

---

### Task 1: Windows build portability

- Modify `t3code-customize`: conditional file locking, LOCALAPPDATA paths, Windows command resolution, Node ZIP downloads and archive overlay prefixes.
- Add focused portability tests in `tests/test_windows.py`; run them before and after implementation.
- Preserve Linux/macOS behavior and run the existing suite where platform dependencies allow.

### Task 2: Windows packaging and lifecycle

- Create `windows.py`: discovery, metadata, split archive staging, source hashes, verified backups and prepared builds, process checks and journal recovery.
- Add fixture lifecycle tests in `tests/test_windows.py` covering install/restore, newer versions, interrupted replacement, missing backups, source changes and native preservation.
- Run `python -m unittest discover -s tests -p test_windows.py -v` and inspect all results.

### Task 3: PowerShell installation and documentation

- Create `install.ps1` and `t3code-customize.ps1`; retain native argument boundaries and exit codes.
- Update `README.md`, `AGENTS.md` and `.github/workflows/verify.yml` with Windows commands, CI and update/recovery workflow.
- Validate PowerShell parsing and help/status invocations.

### Task 4: Real Nightly preparation

- Run `./t3code-customize.ps1 install --build-only --no-pull` against the installed Nightly.
- Resolve actual patch conflicts and required checks without weakening tests. Run all checks in `checks.json` and verify staged bundles.
- Review the diff, report the resulting commands and any live launch limitation. Never close the host app to apply the build.
